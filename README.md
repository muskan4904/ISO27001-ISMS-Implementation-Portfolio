# ISO/IEC 27001:2022 ISMS Implementation Portfolio

## 📌 Project Overview

This repository demonstrates a structured implementation of an Information Security Management System (ISMS) aligned with ISO/IEC 27001:2022.

The portfolio has been developed for **NovaCart Technologies Pvt. Ltd.** and covers key ISMS activities including information security governance, asset management, risk assessment, risk treatment, control applicability, internal auditing, corrective and preventive actions, and management review.

The project demonstrates practical understanding of **GRC, Information Security, Risk Management, ISO 27001 controls, audit processes, and continual improvement**.

---

## 🎯 Objectives

- Define the scope of an Information Security Management System.
- Establish an Information Security Policy.
- Identify and document information assets.
- Identify and assess information security risks.
- Develop a Risk Treatment Plan.
- Determine applicable ISO/IEC 27001:2022 Annex A controls.
- Conduct an internal ISMS audit.
- Document audit results and improvement opportunities.
- Establish corrective and preventive actions.
- Conduct an ISMS management review.
- Demonstrate continual improvement of the ISMS.
