# ISO/IEC 27001 ISMS Implementation Portfolio

## Overview

This repository contains a simulated end-to-end implementation of an Information Security Management System (ISMS) based on **ISO/IEC 27001:2022** for a fictional e-commerce organization.

The objective of this project is to demonstrate practical **Governance, Risk & Compliance (GRC)** skills by creating industry-standard ISMS documentation, performing risk assessments, selecting security controls, and simulating audit and compliance activities.

> **Note:** This is a self-initiated learning project created for educational and portfolio purposes. It does not represent an implementation for a real organization.

---

# Project Scenario

**Organization:** NovaCart Technologies Pvt. Ltd.

**Industry:** E-Commerce

**Employees:** 500

**Headquarters:** Bengaluru, India

**Infrastructure**
- AWS Cloud
- Microsoft 365
- Online Payment Gateway
- Customer Web Portal
- Warehouse Management System

**Objective**

Implement an Information Security Management System (ISMS) aligned with ISO/IEC 27001:2022 and prepare the organization for certification.

---

# Project Objectives

- Define the ISMS Scope
- Identify Information Assets
- Perform Information Security Risk Assessment
- Develop a Risk Register
- Prepare a Risk Treatment Plan
- Select Annex A Controls
- Create a Statement of Applicability (SoA)
- Simulate Internal Audit Activities
- Document Corrective Actions (CAPA)
- Conduct Management Review
